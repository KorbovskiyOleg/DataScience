# PageRank MapReduce Implementation

Реализация алгоритма PageRank с использованием паттерна MapReduce и библиотеки mrjob на Python.

## Быстрый старт

```bash
# 1. Установите зависимости
pip install -r requirements.txt

# 2. Запустите алгоритм
python run_pagerank.py

# 3. Результаты будут в файле pagerank_results.txt
```

## Описание

Этот проект реализует алгоритм PageRank для вычисления важности узлов в ориентированном графе. Алгоритм использует паттерн MapReduce для распределённой обработки данных.

### Алгоритм PageRank

PageRank вычисляет важность каждой страницы (узла) в графе на основе количества и качества входящих ссылок. Формула:

```
PR(A) = (1-d) + d * (PR(T1)/C(T1) + ... + PR(Tn)/C(Tn))
```

где:
- `PR(A)` - PageRank страницы A
- `d` - damping factor (коэффициент затухания, обычно 0.85)
- `T1...Tn` - страницы, ссылающиеся на A
- `C(Ti)` - количество исходящих ссылок из страницы Ti

## Формат входных данных

Входной файл должен содержать описание графа в следующем формате:

```
node_id\tout_link1,out_link2,out_link3
```

Каждая строка представляет один узел и его исходящие ссылки, разделённые запятыми.

**Пример:**
```
A	B,C
B	C
C	A
D	B,C
```

Это означает:
- Узел A ссылается на узлы B и C
- Узел B ссылается на узел C
- Узел C ссылается на узел A
- Узел D ссылается на узлы B и C

## Использование

### Быстрый запуск

```bash
python run_pagerank.py
```

По умолчанию используется файл `graph.txt` с результатами в `pagerank_results.txt`.

### С параметрами

```bash
python run_pagerank.py [input_file] [output_file] [iterations] [damping]
```

**Параметры:**
- `input_file` - путь к файлу с графом (по умолчанию: `graph.txt`)
- `output_file` - путь к файлу результатов (по умолчанию: `pagerank_results.txt`)
- `iterations` - количество итераций (по умолчанию: 10)
- `damping` - damping factor (по умолчанию: 0.85)

**Примеры:**

```bash
# Использование файла по умолчанию
python run_pagerank.py

# Указание входного файла
python run_pagerank.py graph_large.txt

# Полная настройка
python run_pagerank.py graph.txt results.txt 15 0.9
```

### Прямой запуск MapReduce (для одной итерации)

```bash
python pagerank.py --damping 0.85 graph.txt
```

## Как работает MapReduce

### Map фаза
Для каждого узла:
1. Читает текущий ранг узла
2. Распределяет ранг поровну между всеми исходящими ссылками
3. Отправляет вклад ранга каждому целевому узлу

### Reduce фаза
Для каждого узла:
1. Собирает все входящие вклады ранга
2. Вычисляет новый PageRank по формуле
3. Сохраняет структуру графа для следующей итерации

## Примечания

- Алгоритм выполняется итеративно - каждая итерация улучшает точность результатов
- Обычно достаточно 10-20 итераций для сходимости
- Damping factor 0.85 является стандартным значением
- Временные файлы автоматически удаляются после выполнения
