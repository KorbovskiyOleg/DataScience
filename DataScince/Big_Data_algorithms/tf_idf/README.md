# TF*IDF MapReduce Implementation

Реализация алгоритма TF*IDF (Term Frequency * Inverse Document Frequency) с использованием библиотеки MRJob для локального запуска MapReduce приложений.

## Описание

Данный проект реализует алгоритм TF*IDF для ранжирования документов по релевантности поисковому запросу. Алгоритм состоит из нескольких шагов MapReduce:

1. **Подсчет TF (Term Frequency)** - частота термина в документе
2. **Подсчет DF (Document Frequency)** - количество документов, содержащих термин
3. **Вычисление IDF** - обратная частота документа: `IDF = log(N/DF)`, где N - общее количество документов
4. **Вычисление TF*IDF** - произведение TF и IDF для каждого термина в документе
5. **Ранжирование** - сортировка документов по среднему TF*IDF для слов из поискового запроса

## Использование

### Способ 1: Использование скрипта run_tfidf.py

```bash
python run_tfidf.py "машинное обучение"
```

Или интерактивный режим:
```bash
python run_tfidf.py
# Введите поисковый запрос при запросе
```

### Способ 2: Прямой запуск через MRJob

```bash
python tf_idf.py --num-docs 4 --query "машинное обучение" data/*.txt
```

Где:
- `--num-docs` - общее количество документов в коллекции
- `--query` - поисковый запрос (слова через пробел)
- `data/*.txt` - путь к файлам с документами

## Формат входных данных

Входные данные - это текстовые файлы в директории `data/`. Каждый файл представляет один документ. Имя файла используется как идентификатор документа.

## Формат выходных данных

Результат работы программы - упорядоченный список документов по убыванию среднего TF*IDF:

```
doc1.txt	0.123456
doc3.txt	0.098765
doc2.txt	0.045678
```

Где первая колонка - имя файла (документа), вторая - средний TF*IDF для поискового запроса.

## Алгоритм работы

1. **Mapper TF**: Извлекает слова из каждого документа и выдает пары `(doc_id, word) -> 1`
2. **Reducer TF**: Подсчитывает частоту каждого слова в документе: `(doc_id, word) -> tf`
3. **Mapper DF**: Группирует по словам: `word -> (doc_id, tf)`
4. **Reducer TF*IDF**: 
   - Вычисляет DF (количество уникальных документов с словом)
   - Вычисляет IDF = log(N/DF)
   - Вычисляет TF*IDF = TF * IDF для каждого документа
5. **Mapper Query Score**: Фильтрует результаты по словам из запроса
6. **Reducer Query Score**: Вычисляет средний TF*IDF для каждого документа
7. **Reducer Sort**: Сортирует документы по убыванию среднего TF*IDF

## Примечания

- Алгоритм не чувствителен к регистру (все слова приводятся к нижнему регистру)
- Используется регулярное выражение для извлечения слов: `\b\w+\b`
- Для вычисления IDF используется натуральный логарифм
- Средний TF*IDF вычисляется как сумма TF*IDF по словам запроса, деленная на количество слов в запросе
