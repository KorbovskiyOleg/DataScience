ПРОЕКТ: TF*IDF MapReduce Implementation
==========================================

Вариант: 1 (TF*IDF)

Описание:
---------
Реализация алгоритма TF*IDF для ранжирования документов по релевантности 
поисковому запросу с использованием библиотеки MRJob.

Структура проекта:
------------------
- tf_idf.py          - Основной файл с реализацией MapReduce
- run_tfidf.py       - Скрипт для удобного запуска
- requirements.txt   - Зависимости проекта (mrjob==0.7.4)
- README.md          - Подробная документация
- INSTRUCTIONS.md    - Инструкции по упаковке
- data/              - Директория с тестовыми документами
  - doc1.txt
  - doc2.txt
  - doc3.txt
  - doc4.txt

Алгоритм:
---------
1. Подсчет TF (Term Frequency) - частота термина в документе
2. Подсчет DF (Document Frequency) - количество документов с термином
3. Вычисление IDF = log(N/DF), где N - общее количество документов
4. Вычисление TF*IDF = TF * IDF
5. Ранжирование документов по среднему TF*IDF для поискового запроса

Количество шагов MapReduce: 4

Установка:
----------
pip install -r requirements.txt

Запуск:
-------
python run_tfidf.py "машинное обучение"

Или напрямую:
python tf_idf.py --num-docs 4 --query "машинное обучение" data/*.txt

Формат входных данных:
----------------------
Текстовые файлы в директории data/. Каждый файл - один документ.

Формат выходных данных:
-----------------------
Упорядоченный список документов по убыванию среднего TF*IDF:
doc_id    avg_tfidf

Технологии:
-----------
- Python 3.6+
- MRJob 0.7.4
