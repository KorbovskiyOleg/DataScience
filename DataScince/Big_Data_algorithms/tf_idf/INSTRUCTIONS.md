# Инструкции по упаковке проекта

## Подготовка архива для отправки

1. Убедитесь, что все файлы на месте:
   - `tf_idf.py` - основной файл с реализацией
   - `run_tfidf.py` - скрипт для запуска
   - `requirements.txt` - зависимости
   - `README.md` - документация
   - `data/` - директория с тестовыми данными

2. Создайте архив проекта:
   - На Windows: выделите все файлы проекта (кроме временных файлов), щелкните правой кнопкой -> "Отправить" -> "Сжатая ZIP-папка"
   - Или используйте программу архивации (WinRAR, 7-Zip и т.д.)

3. Переименуйте архив согласно требованиям:
   - Формат: `Фамилия_MapReduce_Var1.rar` (или .zip, .gz)
   - Например: `Ivanov_MapReduce_Var1.zip`

4. Проверьте содержимое архива:
   - Должны быть все исходные файлы
   - Директория `data/` с тестовыми документами
   - Файлы документации

## Запуск проекта

### Установка зависимостей:
```bash
pip install -r requirements.txt
```

### Запуск:
```bash
python run_tfidf.py "машинное обучение"
```

Или напрямую:
```bash
python tf_idf.py --num-docs 4 --query "машинное обучение" data/*.txt
```

## Структура проекта для архива

```
Фамилия_MapReduce_Var1.zip
├── tf_idf.py
├── run_tfidf.py
├── requirements.txt
├── README.md
├── INSTRUCTIONS.md
└── data/
    ├── doc1.txt
    ├── doc2.txt
    ├── doc3.txt
    └── doc4.txt
```

## Примечания

- Убедитесь, что в архиве нет временных файлов (например, `~$*.docx`, `*.tmp`)
- Все файлы должны быть в кодировке UTF-8
- Тестовые данные в директории `data/` должны быть включены в архив
