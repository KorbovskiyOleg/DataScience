# Инструкция по использованию MapReduce Text Analysis Engine

## Быстрый старт

### Windows:
```bash
run.bat
```
или
```bash
python main.py
```

### Linux/Mac:
```bash
./run.sh
```
или
```bash
python3 main.py
```

## Функционал

### 1. Запуск проекта
Проект запускается одной командой из командной строки:
- **Windows**: `run.bat` или `python main.py`
- **Linux/Mac**: `./run.sh` или `python3 main.py`

### 2. Отображение статистики
После запуска автоматически отображается:
- Общее количество документов в директории
- Детальная информация по каждому документу:
  - Имя файла
  - Количество слов
  - Количество уникальных слов
  - Определение языка (русский/английский)
- Общая статистика по всем документам

### 3. Поиск по документам
После отображения статистики:
1. Запрашивается путь к директории с документами (по умолчанию: `data`)
2. Запрашиваются слова для поиска (через пробел)
3. Выполняется поиск и отображаются результаты

### 4. Результаты поиска
Для каждого найденного документа показывается:
- Название документа
- Найденные слова и количество вхождений каждого слова
- Общее количество вхождений всех искомых слов
- Релевантность документа (если доступна)

### 5. Интерактивный режим
После каждого поиска можно:
- Ввести новый запрос для поиска
- Ввести `exit` или `quit` для выхода

## Пример использования

```
1. Запустите: python main.py
2. Введите директорию: data (или нажмите Enter для значения по умолчанию)
3. Просмотрите статистику
4. Введите слова для поиска: apple cat
5. Просмотрите результаты
6. Введите новый запрос или exit для выхода
```

## Сохранение существующего функционала

Все существующие скрипты остались без изменений:
- `tf_job.py` - вычисление TF
- `tfidf_job.py` - вычисление TF-IDF
- `search_job.py` - поиск по документам
- `decode_output.py` - декодирование вывода
- `run_tfidf.py` - автоматизация TF-IDF
- `run_tfidf.sh` - shell скрипт для TF-IDF
- `mapreduce_search.sh` - shell скрипт для поиска
- `create_report.sh` - создание отчетов

Все эти скрипты можно использовать независимо от нового функционала.

## Технические детали

- Проект использует библиотеку `mrjob` для MapReduce операций
- Поддерживается обработка текстов на русском и английском языках
- Результаты TF кешируются в файле `tf_output.txt`
- Все операции выполняются через существующие MapReduce задачи
